# SKY STRIKER

5스테이지 레트로 세로형 비행 슈팅 게임. 외부 라이브러리, 로그인, 서버 계정 없이 실행합니다.

## 규칙
- 방향키 / WASD: 이동. 공격: 자동 발사.
- Space / 필살기 버튼: 게이지 100%에서 사용. 탄환 제거 + 일반/엘리트 적 70 피해, 보스 65 피해. 처치로 충전.
- 체력 3. 피격 후 1.4초 무적. 보스 격파 시 체력 1 회복.
- 각 스테이지의 일반 전투 20초 후 보스 등장. 보스를 격파해야 다음 스테이지로 진행.
- 1~4스테이지 중간보스, 5스테이지 최종보스. 최종보스 HP 50%에서 2페이즈. 최종보스 격파 시 클리어.
- 엘리트 적은 조준 부채꼴 탄막, 보스는 서로 다른 탄막과 예고 레이저 필살기를 사용.
- P: 일시정지. R: 현재 모드 재시작. 탭 이탈: 자동 일시정지.
- 터치 화면: 플레이 영역 드래그로 이동, 필살기 버튼 사용.

## 실행
압축을 푼 폴더를 VS Code로 열고 Live Server로 `index.html` 실행.
또는 프로젝트 루트에서 `python -m http.server 8000 ` 실행 후 `http://localhost:8000` 접속.
ES 모듈을 사용하므로 HTML을 파일로 더블클릭하기보다 로컬 서버를 사용합니다.
GitHub Pages에 올릴 때는 이 압축 안의 모든 파일과 tests 폴더를 저장소 루트에 올리면 됩니다.

## 구성
- index.html, style.css: 화면과 반응형 레이아웃
- engine.js: 입력, 게임 상태, 충돌, 적, 5스테이지 보스
- app.js: 캔버스 렌더링, 키보드/터치, 효과, 기록 화면
- backgrounds.js: 스테이지별 구름/황혼 바다/폭풍/요새/우주 배경
- storage.js: 저장값 검증과 손상 복구
- source.html: 공개 소스 확인 화면
- tests/verify.mjs: 실제 시뮬레이션 로직 자동 검사
- tests/results.json: 자동 검사 결과 원본
- TEST-REPORT.md: 증거와 한계
- SUBMISSION.md: 제출용 주소 / 확인법 4줄 / 판단 3줄

## 난이도 비교
30초 시험 비행을 20회 완료하면 A 10회 + B 10회가 기록됩니다.
변경 변수는 `Game.speed` (적 탄환 속도 배수) 하나이며 A=1.00, B=1.25입니다.
HP, 적 등장 간격, 적 체력, 플레이어 속도와 공격은 같습니다. A/B 한 쌍은 같은 seed로 적 등장 순서를 맞춥니다.
기록 화면에서 평균 점수, 생존시간, 30초 생존 횟수를 비교하고 CSV로 내려받습니다.
다시 시작하거나 시험 모드를 전환해서 중단한 판은 기록되지 않습니다.

## 저장 / 공개 안전
최고점수, 끝난 판의 기록(최대 200개), 효과 선택만 이 브라우저의 localStorage에 저장합니다.
저장 키: `sky-striker-v1`. JSON 파싱과 스키마 검증에 실패하면 기본값을 복구합니다.
브라우저가 저장을 차단해도 게임을 계속할 수 있고 저장 불가 안내를 표시합니다.
기록 화면에서 확인 후 초기화할 수 있습니다. 다른 브라우저/시크릿 모드와 기록을 공유하지 않습니다.
개인정보 입력, 로그인, 광고, 분석 추적, 외부 API, 업로드가 없습니다.
효과음 기본 OFF, 화면 효과 선택 가능. 동작 줄이기 OS 설정도 반영합니다.
게임 그래픽은 원본 픽셀 패턴이며 기존 상용 게임의 이미지/음원을 사용하지 않습니다.

## 자동 검사
Node.js 설치 후 프로젝트 루트에서 `node tests/verify.mjs` 실행.
자동 기록은 인간 플레이 기록과 구분합니다. 실제 PC 경계, 10분 브라우저 실행, 20회 직접 플레이는 TEST-REPORT.md의 절차로 확인합니다.

## 배경 및 최종보스 조정
1: 구름 전선, 2: 황혼 바다, 3: 보라색 폭풍, 4: 산업 요새, 5: 우주 궤도. 배경의 난수는 게임의 난수와 분리되어 전투/시험 결과에 영향을 주지 않습니다.
최종보스 탄환 속도는 1페이즈 135→145, 2페이즈 160→175, 원형 탄막 110→120으로 조정했습니다. 공격 간격은 1.45→1.30초, 1.05→0.92초로 줄였습니다. 체력, 레이저 경고 시간, 1~4스테이지 공격은 그대로입니다.

## GitHub Pages 업로드
1. GitHub에서 Public 저장소 sky-striker를 만듭니다.
2. 이 압축을 푼 뒤 그 안의 파일과 tests 폴더를 전부 업로드합니다. 저장소 첫 화면에서 index.html이 보여야 합니다. ZIP 파일 자체만 올리면 게임이 실행되지 않습니다.
3. Settings → Pages → Source: Deploy from a branch → main / (root) → Save.
4. Pages 화면의 Visit site 주소를 새 시크릿 창에서 확인하고 결과물 URL에 넣습니다.
5. 최종 업로드 후 README.md를 열고 Y를 누르면 커밋 고정 주소가 됩니다. 제출용 전체 소스 URL은 https://github.com/계정/sky-striker/tree/실제40자리커밋 형식입니다.
